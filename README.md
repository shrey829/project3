Pattern Generator and Number Analyzer
Overview

This is a beginner-friendly Python project that demonstrates the use of:

User input
match-case statements
Conditional statements (if-else)
for loops
Nested loops
Pattern printing
Number analysis
Sum calculation

The program displays a menu and performs different operations based on the user's choice.

Features
1. Pattern Generator
Accepts the number of rows from the user.
Prints a right-angled triangle using *.
Example

Input

5


Output

*
**
***
****
*****

2. Number Analyzer
Accepts a starting number and an ending number.
Checks whether each number is Even or Odd.
Calculates and displays the sum of all numbers in the given range.
Example

Input

Start = 1
End = 5


Output

Number 1 is odd
Number 2 is even
Number 3 is odd
Number 4 is even
Number 5 is odd

Sum is: 15

3. Exit

Ends the program after displaying a goodbye message.

How to Run
Install Python 3 on your computer.
Save the program as pattern_generator.py.
Open a terminal or command prompt.
Navigate to the project folder.
Run the program using:
python pattern_generator.py
